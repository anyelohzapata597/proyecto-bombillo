Título: "Sistema de Control de Iluminación de bombillo"

Introducción:

- Breve presentación del proyecto: "En este proyecto, hemos diseñado y desarrollado un sistema de control de iluminación utilizando un microcontrolador, con el objetivo de aprender a programar y controlar un bombillo de manera eficiente."
- Objetivos: "Nuestro objetivo es crear un sistema que permita encender y apagar un bombillo de manera remota, utilizando un microcontrolador y un lenguaje de programación."
