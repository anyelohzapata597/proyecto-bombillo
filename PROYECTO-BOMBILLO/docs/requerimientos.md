# Requerimientos

Lista de requerimientos solicitados y cómo se cumplen:

1. El sitio web debe permitir encender y apagar una bombilla usando solo HTML, CSS y JS.
   - Implementado en `index.html`, `styles.css`, `script.js`.
2. Deben haber dos botones: `Encender` y `Apagar`.
   - Botones con `id="onBtn"` y `id="offBtn"` en `index.html`.
3. Debe ser responsive para mobile, tablet y desktop.
   - Media queries en `styles.css` para ajustar tamaños y layout.
4. Usar colores amigables y estilo claymorfismo.
   - Paleta suave y sombras internas/exteriores en `styles.css`.
5. Código con buenas prácticas, eficiente y limpio.
   - Código modular, funciones pequeñas y separación de responsabilidades.
6. Documentar todo el código con comentarios y JSDoc.
   - `script.js` incluye JSDoc y comentarios en español.
7. Crear un documento de explicación técnica para personas que están aprendiendo.
   - `docs/arquitectura.md` y `docs/plan-de-implementacion.md` contienen explicaciones.
