# Plan de Implementación

Objetivo: Entregar una demo simple y documentada para el control de una bombilla.

Pasos:

1. Crear estructura del proyecto y carpeta `docs/`.
2. Implementar `index.html` con marca semántica y controles.
3. Añadir `styles.css` con claymorfismo y media queries.
4. Implementar `script.js` con JSDoc, funciones `turnOn`/`turnOff` y `updateUI`.
5. Documentar la arquitectura y requisitos en `docs/`.
6. Probar en mobile/tablet/desktop para verificar responsive.
7. Mantener `docs/readme.md` actualizado tras cada cambio.

Tareas futuras (opcional):
- Añadir pruebas unitarias sencillas para la lógica JS.
- Extender accesibilidad (más soporte ARIA y pruebas con lectores de pantalla).
